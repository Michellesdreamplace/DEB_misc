# Syntax Highlighting in Kate:

### Folge den Anweisungen auf:
https://github.com/KDE/syntax-highlighting
### 
### Lade eine Jinja2/Kate xml‑syntax *.xml / *.syntax aus GitHub herunter:
https://raw.githubusercontent.com/KDE/syntax-highlighting/refs/heads/master/data/syntax/jinja.xml

### Kopiere die Datei nach ~/.local/share/org.kde.syntax-highlighting/syntax/ (erstelle die Ordner falls nötig).

### Starte Kate neu. Die neue Sprache erscheint unter Ansicht → Highlighting.
